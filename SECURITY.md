# Security policy

## Supported version

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. After the repository is published, use GitHub's private vulnerability reporting feature or the security contact listed in the repository profile.

Include the affected registry item or route, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within five business days.

Flag images are loaded from `https://flagcdn.com`. Applications with a strict Content Security Policy must allow that origin in `img-src` or proxy the assets through an approved origin.
